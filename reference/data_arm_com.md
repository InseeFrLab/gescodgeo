# Table de passage entre les arrondissements municipaux et les communes de Paris, Lyon et Marseille

Table de passage entre les arrondissements municipaux et les communes de
Paris, Lyon et Marseille

## Usage

``` r
data_arm_com
```

## Format

Une data frame avec 2 variables :

- COM:

  Code commune

- ARM:

  Code arrondissement

Pour plus de détails sur le code officiel géographique
<https://www.insee.fr/fr/information/2560452>
