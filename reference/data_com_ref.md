# Base communale de référence

Base intermédiaire utilisée par les bases communales antérieures.

## Usage

``` r
data_com_ref
```

## Format

Une data frame avec 34945 lignes et 1 variable :

- COM:

  Code géographique en 2023

Pour plus de détails sur le code officiel géographique
<https://www.insee.fr/fr/information/2560452>
