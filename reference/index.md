# Package index

## Principales fonctions

- [`change_cog()`](change_cog.md) : Change l'année du code officiel
  géographique des communes
- [`check_cog()`](check_cog.md) : Vérifie le code géographique des
  communes
- [`cog_transition()`](cog_transition.md) : Table de passage entre deux
  années du code officiel géographique des communes
- [`cog_events()`](cog_events.md) : Évènements du code officiel
  géographique
- [`adapt_to_change()`](adapt_to_change.md) : Modifie une data frame
  pour prendre en compte les changements de géographie
- [`data_com()`](data_com.md) : Base des codes des communes selon
  l'année du code officiel géographique
- [`filter_mayotte()`](filter_mayotte.md) : Enlève (ou pas) les communes
  de Mayotte, selon l'année du code officiel géographique
- [`com_to_arm()`](com_to_arm.md) : Convertit les communes en
  arrondissements municipaux
- [`arm_to_com()`](arm_to_com.md) : Convertit les arrondissements
  municipaux en communes
- [`com_to_dep()`](com_to_dep.md) : Convertit les communes en
  départements
- [`reg_to_dep()`](reg_to_dep.md) : Convertit les régions en
  départements
- [`dep_to_reg()`](dep_to_reg.md) : Convertit les départements en
  régions

## Données du package

- [`data_table_passage`](data_table_passage.md) : Table de passage du
  code officiel géographique des communes
- [`data_arm_com`](data_arm_com.md) : Table de passage entre les
  arrondissements municipaux et les communes de Paris, Lyon et Marseille
- [`data_dep_reg`](data_dep_reg.md) : Table de passage entre les codes
  des départements et les codes des régions
- [`cog_max`](cog_max.md) : Plus grande année disponible
- [`cog_min`](cog_min.md) : Plus petite année disponible
- [`cog_ref`](cog_ref.md) : Année de la base communale de référence
- [`data_com_ref`](data_com_ref.md) : Base communale de référence

## Utiliser des tables de passage personalisées

- [`codes_to_many()`](codes_to_many.md) : Merge or split geographic
  codes
- [`codes_to_one()`](codes_to_one.md) : Merge geographic codes
