# Table de passage entre les codes des départements et les codes des régions

Table de passage entre les codes des départements et les codes des
régions

## Usage

``` r
data_dep_reg
```

## Format

Une data frame avec 2 variables :

- REG:

  Code région

- DEP:

  Code département

Pour plus de détails sur le code officiel géographique
<https://www.insee.fr/fr/information/2560452>
